## What is this?

This is a simple interest calculator built with Next.js 13, TypeScript, Tailwind CSS, and pnpm.

It allows users to calculate the interest on a given principal amount over a specified period of time at a certain interest rate.

To get UP and running, clone the repository and install the dependencies using pnpm, and then run the development server with `pnpm dev`. You can then access the application in your web browser at `http://localhost:3000`.

## Homepage

the `/` route is the base route for the compounding interest calculator.

## Testing

the interest calculator has been built with Vitest, tests have been built first, and pages/functionality has followed.

to run the tests, use the command `pnpm test`.
